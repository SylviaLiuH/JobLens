# JobLens

## 项目简介

JobLens 是一个面向大学生和应届毕业生的 AI 求职岗位分析工具。

项目通过收集和分析真实招聘 JD，帮助用户了解目标岗位的技能要求、
招聘趋势以及自身能力缺口。

## 核心功能

1. 招聘岗位数据整理与存储
2. 岗位技能关键词统计
3. 招聘数据可视化
4. AI JD 分析
5. 简历与岗位匹配分析

## 技术栈

Python
SQL
Pandas
Data Visualization
LLM API
Streamlit
